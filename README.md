Система учета товаров с классами `Product`, `Smartphone`, `LawnGrass` и `Category`

Этот проект реализует простую систему учета товаров с использованием классов Product, Smartphone, LawnGrass и Category.

## Функции

  * Класс Product с атрибутами: название, описание, цена и количество.
  * Классы-наследники Smartphone и LawnGrass с дополнительными атрибутами.
  * Класс Category с атрибутами: название, описание и список товаров.
  * Автоматический подсчет количества категорий и товаров.
  * Методы для добавления товаров в категорию и получения списка товаров.
  * Геттеры и сеттеры для атрибута цены в классе Product.
  * Магический метод сложения для класса Product и его наследников (Smartphone и LawnGrass).
  * Ограничения на сложение и добавление товаров разных классов (реализована проверка типов).

## Установка

1. Клонируйте этот репозиторий.
2. Установите зависимости с помощью `poetry install`.
