# Система учета товаров с классами Product и Category

Этот проект представляет собой простую систему учета товаров, реализованную на Python с использованием классов `Product` и `Category`.

## Описание

Система позволяет хранить информацию о товарах и объединять их в категории, автоматически подсчитывая общее количество категорий и товаров.

## Функциональность

*   Класс Product: Представляет товар и содержит следующие атрибуты:
    *   name: Название товара (строка).
    *   description: Описание товара (строка).
    *   price: Цена товара (число с плавающей точкой).
    *   quantity: Количество товара в наличии (целое число).

*   Класс Category: Представляет категорию товаров и содержит следующие атрибуты:
    *   name: Название категории (строка).
    *   description: Описание категории (строка).
    *   products: Список товаров (`Product`), принадлежащих к данной категории.
    *   category_count: (Атрибут класса) Общее количество созданных категорий.
    *   product_count: (Атрибут класса) Общее количество товаров во всех категориях.
